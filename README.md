
🌤️ Responsive Weather Dashboard
A sleek, real-time weather forecasting application built with Vanilla JavaScript and the OpenWeatherMap API. This project demonstrates asynchronous data fetching, dynamic DOM manipulation, and responsive UI design.

🚀 Features
-->Real-Time Data: Fetches current temperature, humidity, wind speed, and atmospheric pressure.

-->Smart Search: Supports searching by city name with "Enter" key functionality for better UX.

-->Error Handling: Comprehensive alerts for invalid city names, API issues, or empty inputs.

-->Fully Responsive: Optimized for desktop, tablet, and mobile devices using CSS Grid and Flexbox.

-->Loading States: Visual feedback (spinner) while data is being retrieved.

🛠️ Tech Stack
-->Frontend: HTML5, CSS3 (Custom Properties & Animations).

-->Scripting: JavaScript (ES6+), Fetch API, Async/Await.

-->API: OpenWeatherMap API.
